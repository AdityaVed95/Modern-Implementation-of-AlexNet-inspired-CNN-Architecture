# Modern-Implementation-of-AlexNet-inspired-CNN-Architecture

### ▷ Files & Description : 

👉 Modern_implementation_of_AlexNet_inspired_cnn_architecture.ipynb file contains the architecture diagram and the code to implement the architecture from scratch using tensorflow.

👉 model.png file contains the image of the architecture diagram.

### ▷ Key Modern Techniques Utilized (which weren't used in original AlexNet) : 

1. Batch Normalization (instead of Local Response Normalization)

2. AdamW Optimizer (instead of Stochastic Gradient Descent)

3. Using Weight Decay (L2 like Regularization) for shrinking weights to avoid overfitting.
